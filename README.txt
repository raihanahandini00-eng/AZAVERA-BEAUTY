AZAVÉRA Beauty - Website HTML CSS JavaScript

1. Ekstrak ZIP.
2. Buka folder AZAVERA-Beauty di Visual Studio Code.
3. Jalankan index.html menggunakan ekstensi Live Server atau klik dua kali file index.html.
4. Gunakan menu About Us untuk halaman kedua.
5. Klik Lihat Detail untuk melihat penjelasan produk. Ikon pencarian juga dapat digunakan.

File:
- index.html : halaman utama
- about.html : halaman Tentang Kami
- style.css : tampilan desktop dan mobile
- script.js : interaksi menu, pencarian, detail produk
- assets/ : foto hasil potongan gambar referensi yang diberikan pengguna

Catatan: foto diambil dari gambar mockup yang Anda kirim. Untuk website produksi, gunakan foto produk asli dan verifikasi semua klaim produk.
